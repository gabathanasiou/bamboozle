# Android Asset Integration Guide

Follow these practical steps to apply the graphics generated by the **Asset Generator** to your Android app using standard Capacitor workflows.

## 1. Prepare your Source Assets
First, use the [Asset Generator](http://localhost:3001) to export the following files and save them into the `/assets` folder at the root of the project:

| Asset Type | Export Settings | Save As |
| :--- | :--- | :--- |
| **App Icon** | Icon tab → Square → 512px+ → 4X Export | `assets/icon.png` |
| **Splash Screen**| Loading Screen tab → **Tablet Preset** → 8X Export | `assets/splash.png` |

> [!IMPORTANT]
> **Use the Tablet Preset for your Splash Screen.** 
> Android and iOS are better at "cropping" a big square image to fit a tall phone screen than they are at "stretching" a narrow phone image to fit a wide tablet. By using the **Tablet Preset**, you ensure the grid fills the screen on all devices without looking blurry or cut off.

## 2. Install the Asset Tool
Capacitor has an official tool that takes your high-res source images and automatically generates the dozens of different sizes required by Android.

Run this in your terminal:
```bash
npm install -g @capacitor/assets
```

## 3. Generate & Sync
Once you have your source images in the `/assets` folder, run these two commands to update the Android project:

```bash
# 1. Generate the native density folders (mipmap, drawable, etc.)
npx @capacitor/assets generate --android

# 2. Sync the changes with the Android platform
npx cap sync android
```

## 4. Final Verification in Android Studio
1. Open your project in **Android Studio**.
2. Go to **File > Sync Project with Gradle Files**.
3. Run the app on your device/emulator to see the new icon and splash screen!

## 5. Market Graphics (Play Store)
The **Store Banner** assets you generate are NOT part of the app code. Instead:
1. Export your banner at **8X quality**.
2. Upload it directly to the **Google Play Console** under **Grow > Store presence > Main store listing**.
